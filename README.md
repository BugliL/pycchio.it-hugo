# Pycchio.it 

**L'ho fatto in python un po' ad occhio.**


[![Build and deploy](https://github.com/BugliL/pycchio.it-hugo/actions/workflows/hugo-publishing.yaml/badge.svg)](https://github.com/BugliL/pycchio.it-hugo/actions/workflows/hugo-publishing.yaml)

Hugo blog to write articles about programming and experiences in the IT world.
The name is a play on words between "python", the programming language, and
"occhio", that means "eye" in Italian. 

This is a old joke of "Fermi tutti questo e' uno spettacolo", a 
theatrical performance by Massimo Ceccherini and Alessandro Paci:
"L'ho fatto con un pino, un po' ad occhio, lo chiamero' Pinocchio"
